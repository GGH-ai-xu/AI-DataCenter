# Start Dev Launcher Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a Windows one-click development launcher that starts `server-agent`, `backend`, and `frontend` on available ports.

**Architecture:** Use a root batch entry point that invokes one PowerShell orchestrator. The orchestrator finds free localhost ports, validates prerequisites, starts each process with runtime environment injection, waits for readiness endpoints, then opens the browser. Vite reads backend proxy targets from environment variables so no config files are rewritten at runtime.

**Tech Stack:** Windows batch, PowerShell, Python `.venv`, npm, Vite

### Task 2: Add the Windows launcher entry point

**Files:**
- Create: `start-dev.bat`

- [ ] **Step 1: Create the batch launcher**

Add a root `start-dev.bat` that runs:

```bat
@echo off
setlocal

powershell -ExecutionPolicy Bypass -File "%~dp0scripts\start-dev.ps1"
if errorlevel 1 exit /b %errorlevel%
```

- [ ] **Step 3: Start the three services with dynamic ports**

Start:
- agent with `GPU_AGENT_PORT=<agentPort>`
- backend with `PORT=<backendPort>` and `AGENT_URL=http://127.0.0.1:<agentPort>`
- frontend with `DEV_BACKEND_URL=http://127.0.0.1:<backendPort>`, `DEV_BACKEND_WS_URL=ws://127.0.0.1:<backendPort>`, and `npm run dev -- --host 127.0.0.1 --port <frontendPort>`

- [ ] **Step 4: Wait for readiness and open browser**

Poll:
- `http://127.0.0.1:<agentPort>/api/health`
- `http://127.0.0.1:<backendPort>/api/health`
- `http://127.0.0.1:<frontendPort>/`

Only after all pass, open `http://127.0.0.1:<frontendPort>/`.
